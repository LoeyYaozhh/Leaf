### 关于新增 `vitest.config.ts`（重要，非源码改动）

- `vite.config.ts:7-31` 定义了 `resolve.alias['@']`，`src/domain/**` 内部大量使用 `@/types/domain`、`@/constants/app`。Vitest 默认复用 `vite.config.ts`，会连带加载 `VitePWA` 与 `@vitejs/plugin-react` 插件，存在测试进程被构建期插件干扰的风险。
- 新增独立 `vitest.config.ts` 后，Vitest 优先读取它，**完全不加载** `vite.config.ts`；别名在其中显式重建（与 `vite.config.ts:10` 同一写法），`environment: 'node'` 保证零 DOM 依赖。
- 该文件**不影响** `npm run dev` / `npm run build`（Vite 仍只读 `vite.config.ts`），也不在 `tsconfig.json:25` / `tsconfig.node.json:14` 的 `include` 范围内，不进入 `npm run build` 的类型检查。
- 测试目录 `tests/` 同样不在 `tsconfig.json` 的 `include`（仅 `src`），测试代码不会进入 `npm run build` 的类型检查。
